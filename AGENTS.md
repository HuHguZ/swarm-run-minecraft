# NeuroDown — правила проекта (для Codex и любого агента)

Бот **NeuroDown** (mineflayer, Minecraft Java 1.21.11, Paper) сам проходит игру по-спидраннерски, до
убийства дракона; второе направление — арена PvP с роем ботов против людей.

## С чего начать
- **Текущее состояние** — раздел «Сейчас» в начале `HANDOFF.md`, открытое — `TODO.md`. Старая история — `research/archive/`
  (читать только по нужде). Записи сессий в HANDOFF — короткие (≤ 15 строк), старые — в архив.
- **Механика и тактики** — `SPEEDRUN.md`, сверено с 1.21.11. PvP — `PVP-RESEARCH.md`.
- **Код:** TypeScript (ES-модули, сборка tsc в CommonJS).
  - `daemon/src` — тело бота, демон с WebSocket RPC;
  - `daemon/campaign.ts` — вход автомата этапов, сам автомат — `daemon/campaign/` (flags, state, навыки, `stages/*`, `loop`);
  - сцены фермы — `daemon/scenes/<этап>/` (общий код — `scenes/lib/`), `farm.js run` находит сцену по имени файла;
  - сборка: `npm run build` → `dist/` (та же раскладка, что у исходников; рядом с `.ts` собранного кода нет);
    запуск — из `dist/`: `node dist/daemon/campaign.js`, `node dist/farm/farm.js`, `node dist/run/rpc.js`;
  - типы: `npm run typecheck` (весь проект + строгая зона `tsconfig.core.json`), ошибок быть не должно;
  - тесты: `npm test` (сборка + тесты из `dist/`), все зелёные;
  - пути к данным, логам, памяти и мирам — от `REPO_ROOT` (`daemon/src/paths.ts`), не от `__dirname`: из `dist/`
    `__dirname` указывает в сборку. От `__dirname` строятся только пути к собранным `.js`.
- **Ферма тестовых миров** — `node dist/farm/farm.js`, справка без аргументов. Слоты 1..32: сервер 25600+i, RCON 25700+i,
  демон ws 8800+i.
- **Основной мир** — `server-run`: игра 25569, RCON 25579, демон 8769. Запуск, остановка и кампания — `run/*.ps1`, `dist/run/*.js`.
- **Репозиторий (с 04.10.2026)** — github.com/HuHguZ/neurodown, ветка `main`; пока **приватный** — публиковать, когда
  пользователь скажет, что проект доделан. `.gitignore` — белый список:
  код, тесты, сиды и основные документы. Миры, логи, память бота, `HANDOFF.md`, `TODO.md`, `research/`, `codex-lab/`
  остаются только на диске. Коммит и push — только по просьбе пользователя. Перед коммитом — `npm test` и проверка,
  что в набор не попали секреты, jar-файлы и логи. Код проиндексирован CodeGraph (`.codegraph/`, вне git).

## Жёсткие правила пользователя
- **Честная игра основного бота.** Никаких `/tp`, `/give`, `/effect`, `/time`, бот не оп.
  На ферме команды можно.
- **Инвентарь при смерти (пользователь, 02.10.2026):** в боевом режиме спидрана инвентарь НЕ сохраняется (`keep_inventory=false`): смерть — потеря вещей и времени, бот в спидране умирать не должен. Серии кампании и этапов на ферме меряются с `keep_inventory=false`, смерть = провал прогона. (В server-run сейчас стоит true во всех трёх мирах — переключать при запуске боевого прогона, с согласия пользователя.)
- **Сиды (пользователь, 02.10.2026):** пока спидран оттачиваем только на хороших сидах — пул `farm/seeds/good-v2.json` (300 сидов, с лавой по скану; `node dist/farm/farm.js up N --from <слот> --pool --fresh`), подбор — `tools/seedtool` (README там). Ночью в спидране не спать и не пережидать: на хорошем сиде в каждую минуту есть дело, цель — Ад до первой ночи.
- **Не бить и не ставить блоки сквозь стены.** Удар и установка — только по тому, что видит прицел клиента (`pick.js`).
- **Гибкость вместо жёстких правил (пользователь, 06.10):** жёсткое условие стратегии или навыка допустимо только для
  физической необходимости (без очей портал не открыть, без кирки обсидиан не добыть). Всё остальное — «к ифритам только
  с огнестойкостью», «без N досок не идти», пороги и флаги-запреты — это цена и риск, которые считаются от состояния и
  сравниваются с альтернативами. У навыков есть варианты для худших условий: нет огнестойкости — бой из укрытия,
  уклонение, щит, отход и возврат, а не отказ. Если условие исчезло посреди навыка, решает оценка, а не обрыв.
- **Хп противника-игрока — только оценкой (пользователь, 06.10):** точное здоровье из метаданных сущности в решениях
  боя против игрока не использовать — человек его не видит, это чит. Бот оценивает хп по своим подтверждённым попаданиям
  (модель урона), видимому лечению (еда, золотые яблоки, зелья, тотем) и естественной регенерации; вне видимости
  оценка только расплывается. Точное хп — для мобов и для телеметрии/замеров сцен фермы, но не для решений против игрока.
- **Ресурсы — сначала из построек (пользователь, 03.10):** в спидране всё, что можно взять в постройках (сундуки, голем, сено, кровати, обсидиан/огниво руин, корабли, клады, храмы, иглу…), берётся оттуда (постройки бот находит сам — глазами, «пирогом» F3, звуком; см. правило ниже); шахта и копка руды — только если в постройках не нашлось. Бюджет поиска построек и момент перехода к копке — явными числами в плане и логе.
- **Что бот знает о мире — как игрок на случайном сиде (пользователь, 07.10; заменяет правило 03.10 о карте копии):**
  главная метрика спидрана — без карты сида и без скана копии. Бот знает только то, что узнал бы человек в игре:
  - глаза: блоки и сущности по лучу видимости в пределах прорисовки (рельеф, деревья, вода, гравий, видимая руда в стенах
    пещер, мобы) и то, что он раньше видел сам (память увиденного);
  - экран F3: координаты, направление, биом под ногами, свет, число сущностей вокруг;
  - «пирог» F3: есть ли рядом, в прорисованных чанках, сундуки или спавнер — без точной клетки, место ищется ходом;
  - звук с субтитрами: сторона и примерная дальность мобов, лавы, воды, портала («слух» ND_OW_HEAR);
  - око эндера и прочие игровые подсказки.
  Нельзя: рентген (руда и пустоты под землёй, сущности и сундуки за стенами без звука), карта сида (seedtool, /locate),
  скан копии (лава, золото бастиона, сетки маршрутов), точное хп игрока. Прогоны со знанием карты сида или копии мира —
  только отдельными строками («как на известном сиде», «полный скан»), не в главной метрике.
- **Жемчуг — бартером в бастионах, как у спидраннеров.** Эндермены — добор, когда бартера не хватило (пользователь 07.10: «можно
  из эндерменов нафармить, если не вышло выторговать у пиглинов»); выбор — по цене, без жёстких ворот.
- **Без манипуляции ГСЧ и сидом в основном мире.** На ферме — сброс `/random reset` перед прогоном, иначе
  копии мира не независимы.
- **Механику сверять с данными 1.21.11**: декомпиляция, jar. Не подбирать коэффициенты вслепую.
- **Имя бота — NeuroDown.** Не менять.
- **Остановка основного мира — строго по порядку:**
  1. `./run/run-campaign.ps1 -Stop`;
  2. сразу `node dist/run/rpc.js disconnect '{"reason":"стоп"}'`;
  3. `./run/run-daemon.ps1 -Stop`;
  4. `node dist/run/rcon.js stop`.

## Ресурсы: ПК общий с игрой пользователя
Режим задаёт `farm/limits.json`:
- **пользователь играет** — `{"maxUp": 4, "cores": "ccd1"}`: не больше 4 миров, считая server-run, ядра 16–31;
- **не играет** — до 30 миров, все ядра.
- **человек играет на арене** (пользователь 22.10) — драйвер арены сам даёт серверу и демонам ботов обычный приоритет и все
  ядра, пока там живой игрок (farm/arena/fleet.ts boost; ARENA_BOOST=0 — выкл.).

Сменил режим — выполни `node dist/farm/farm.js nice`: команда переводит уже поднятые процессы на новый режим. Если сомневаешься, играет ли он, — ставь щадящий режим.
Долгие процессы запускай в фоне с выводом в файл. После опытов процессы не оставляй.
