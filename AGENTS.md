# NeuroDown — правила проекта (для Codex и любого агента)

Бот **NeuroDown** (mineflayer, Minecraft Java 1.21.11, Paper) сам проходит игру по-спидраннерски, до
убийства дракона. Работа передана Codex 30.09.2026.

## С чего начать
- **Текущее состояние** — самая верхняя запись `HANDOFF.md` («Передача Codex …»). Всё ниже неё — история.
- **Механика и тактики** — `SPEEDRUN.md`, сверено с 1.21.11. PvP — `PVP-RESEARCH.md`.
- **Код:**
  - `daemon/src` — тело бота, демон с WebSocket RPC;
  - `daemon/campaign.js` — автомат этапов;
  - тесты: `cd daemon && npm test`, все зелёные.
- **Ферма тестовых миров** — `node farm/farm.js`, справка без аргументов. Слоты 1..32: сервер 25600+i, RCON 25700+i,
  демон ws 8800+i.
- **Основной мир** — `server-run`: игра 25569, RCON 25579, демон 8769. Запуск, остановка и кампания — `run/*.ps1`, `run/*.js`.
- **Репозиторий (с 04.10.2026)** — публичный github.com/HuHguZ/neurodown, ветка `main`. `.gitignore` — белый список:
  код, тесты, сиды и основные документы. Миры, логи, память бота, `HANDOFF.md`, `TODO.md`, `research/`, `codex-lab/`
  остаются только на диске. Коммит и push — только по просьбе пользователя. Перед коммитом — `npm test` и проверка,
  что в набор не попали секреты, jar-файлы и логи. Код проиндексирован CodeGraph (`.codegraph/`, вне git).

## Жёсткие правила пользователя
- **Честная игра основного бота.** Никаких `/tp`, `/give`, `/effect`, `/time`, бот не оп.
  На ферме команды можно.
- **Инвентарь при смерти (пользователь, 02.10.2026):** в боевом режиме спидрана инвентарь НЕ сохраняется (`keep_inventory=false`): смерть — потеря вещей и времени, бот в спидране умирать не должен. Серии кампании и этапов на ферме меряются с `keep_inventory=false`, смерть = провал прогона. (В server-run сейчас стоит true во всех трёх мирах — переключать при запуске боевого прогона, с согласия пользователя.)
- **Сиды (пользователь, 02.10.2026):** пока спидран оттачиваем только на хороших сидах — пул `farm/seeds/good-v2.json` (300 сидов, с лавой по скану; `node farm/farm.js up N --from <слот> --pool --fresh`), подбор — `tools/seedtool` (README там). Ночью в спидране не спать и не пережидать: на хорошем сиде в каждую минуту есть дело, цель — Ад до первой ночи.
- **Не бить и не ставить блоки сквозь стены.** Удар и установка — только по тому, что видит прицел клиента (`pick.js`).
- **Ресурсы — сначала из построек (пользователь, 03.10):** в спидране всё, что можно взять в постройках (сундуки, голем, сено, кровати, обсидиан/огниво руин, корабли, клады, храмы, иглу…), берётся оттуда по карте; шахта и копка руды — только если в постройках не нашлось. Бюджет поиска построек и момент перехода к копке — явными числами в плане и логе.
- **Знание карты из копии мира — в главной метрике (главный, 03.10):** структуры по `tools/seedtool`, лава по скану копии (`farm/seeds/good-v2.json`) — можно в плане маршрута; вслепую — отдельной строкой. «Слух» (ND_OW_HEAR: лава и вода в 16 бл. за стеной — только сторона и дальность, как звук) — разрешён пользователем 03.10, по умолчанию включён.
- **Жемчуг — бартером в бастионах, как у спидраннеров.** Эндермены в Аду — только добор после всех бастионов.
  Знание карты из копии этого же мира (второй бастион, точки обзора, крепость) — разрешено.
- **Без манипуляции ГСЧ и сидом в основном мире.** На ферме — сброс `/random reset` перед прогоном, иначе
  копии мира не независимы.
- **Механику сверять с данными 1.21.11**: декомпиляция, jar. Не подбирать коэффициенты вслепую.
- **Имя бота — NeuroDown.** Не менять.
- **Остановка основного мира — строго по порядку:**
  1. `./run/run-campaign.ps1 -Stop`;
  2. сразу `node run/rpc.js disconnect '{"reason":"стоп"}'`;
  3. `./run/run-daemon.ps1 -Stop`;
  4. `node run/rcon.js stop`.

## Не трогать никогда
- Клиент Minecraft пользователя (javaw), java TLauncher'а, его LAN-мир.
- Живую арену: демоны 8765/8768, `daemon-live/`, `daemon-stage/`, `deploy-*`, колизей в мире пользователя.
  Выкладка — только с согласия пользователя.
- `server/` на 25565, MCP-мосты.

## Ресурсы: ПК общий с игрой пользователя
Режим задаёт `farm/limits.json`:
- **пользователь играет** — `{"maxUp": 4, "cores": "ccd1"}`: не больше 4 миров, считая server-run, ядра 16–31;
- **не играет** — до 30 миров, все ядра.

Сменил режим — выполни `node farm/farm.js nice`: команда переводит уже поднятые процессы на новый режим. Если сомневаешься, играет ли он, — ставь щадящий режим.
Долгие процессы запускай в фоне с выводом в файл. После опытов процессы не оставляй.
