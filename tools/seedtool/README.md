# seedtool — подбор сидов 1.21.11 для фермы

Консольная утилита на библиотеке [cubiomes](https://github.com/Cubitect/cubiomes) (та же, что внутри cubiomes-viewer).

- Клон с GUI: `C:\Users\user\Desktop\work\cubiomes-viewer`, программа — `bin\cubiomes-viewer-static-w64.exe` (релиз 4.1.2).
- Библиотека — подмодуль `cubiomes`, ветка **`nd-1.21.11`**. В master нет поддержки новее 1.21.4, поэтому поверх неё взяты открытые PR:
  - #162 — дерево биомов 1.21.5+, снятое с `1.21.11.jar` (`MC_1_21_11`);
  - #145 — тип нижнего разрушенного портала;
  - #141 — правило cherry_grove для стронгхолдов, действует с 1.21.9.
- GUI-релиз 4.1.2 собран без этих правок: он показывает генерацию 1.21.4 (отличается бледный сад). Агентам — только `seedtool.exe`.

## Запуск

```
tools\seedtool\seedtool.exe info <сид> [<сид> ...]
tools\seedtool\seedtool.exe search [условия] [--count N] [--start S] [--max M]
```

**Условия** — радиус в блоках:
- от точки спавна: `--village`, `--rp` (разрушенный портал), `--shipwreck`, `--treasure` (клад), `--temple` (пустынный или джунглевый храм), `--outpost`, `--igloo`, `--ocean_ruin`, `--trail_ruins`, `--trial_chambers`, `--ancient_city`, `--mansion`, `--monument`, `--swamp_hut`, `--sh` (ближайший стронгхолд);
- в Аду — от спавна/8, то есть от места, где встанет портал, построенный у спавна: `--bastion`, `--fortress`, `--nether-rp`.

Вывод — по строке JSON на сид: `spawn`, `biome` спавна, ближайшая структура каждого вида `{x,z,d}` или `null`, а также `sh` с координатами для Ада (`nether`).

**Режимы поиска:**
- `--start S` — перебор подряд с сида S (воспроизводимо);
- без `--start` — случайные сиды.

Скорость — тысячи сидов в секунду: пример ниже дал 5 сидов за 1 с.

### Примеры

```
# спидран-старт: руина ≤ 150, деревня ≤ 300, в Аду бастион ≤ 150 и крепость ≤ 250
seedtool.exe search --rp 150 --village 300 --bastion 150 --fortress 250 --count 10

# только Ад для сцены бастиона
seedtool.exe search --bastion 100 --count 20

# что в сиде основного мира
seedtool.exe info 5709596442716969862
```

На ферму сиды ставятся так: `node farm/farm.js up <N> --seeds s1,s2,... --fresh` с явными слотами своего диапазона (справка — `node farm/farm.js` без аргументов).

## Точность

**Сверено:**
- **Основной мир** (сид 5709596442716969862):
  - стронгхолд: seedtool −396,1780 — в игре комната у −400,1776 (HANDOFF);
  - бастион: seedtool 64,128 — бот был в бастионе у 105,43,87, это в пределах постройки.
- **Список пользователя** (research/seeds-user-1.21.11.json): там, где расстояния указаны, всё совпадает с точностью ±10 блоков:
  - 8376837612225836466 — руина 288 (в списке ~278), деревня 544 (~555), стронгхолд 1529 (~1530);
  - 717906078373382497 — руина 65 (~57), деревня 150 (~140);
  - −3051638814131239578 — руина 115 (~104), корабль 230 (~220), деревня 350 (~347).

**Чего cubiomes не знает:**
- лава: озёра — это фичи, а не структуры. Лаву ищи сканом на сервере, см. поток portal-tech;
- содержимое сундуков;
- рельеф: в 1.18+ деревня или корабль иногда не встают на месте;
- точный кусок бастиона.

Позиция структуры — это точка её генерации. Если важна точность — проверь `/locate` на сервере.
